## 2. Controls Cheat Sheet

| Input | Action | In-Game Description |
| :---: | :--- | :--- |
| **`W A S D`** | Move Player | Standard third-person character movement |
| **`Space`** | Jump | Leap over small terrain steps and obstacles |
| **`Shift`** | Sprint | Double movement velocity across open plazas |
| **`E`** | Interact | Trigger beacons, open chests, collect the Lost Core |
| **`F`** | Use Ability | Fire the active Funobot companion's special ability |
| **`1`** | Select Petalo | Light & Signalling (illuminates caves, activates runes) |
| **`2`** | Select Quacky | Movement & Delivery (scouting dash, dissolves brambles) |
| **`3`** | Select Tiko | Object Manipulation (kinetic arm, extends bridge gears) |
| **`4`** | Select Tolly | Tollgate & Access (security scanner, lowers gates) |

## 3. Recommended 5-Minute Evaluator Walkthrough

1. **Beacon Onboarding**: Walk forward through the Grand Gateway and step into the glowing Beacon. Mission activates!
2. **Meet the Squad**: Walk into the Funobotz Hub Plaza to inspect all 4 companion robots.
3. **Forest Bramble**: Walk northeast toward the thorny vines. Press `2` to select Quacky, then press `F`. Watch the brambles dissolve into leaves!
4. **Rainbow Bridge**: Proceed to the canyon chasm. Press `3` to select Tiko, then press `F`. Watch the mechanical bridge extend across the canyon!
5. **Mystery Cave**: Enter the dark cavern. Press `1` to select Petalo, then press `F`. The cave lights up and wall runes activate!
6. **Ancient Vault**: Approach the massive stone gate. Press `4` to select Tolly, then press `F`. The vault gate opens!
7. **The Lost Core**: Walk into the Core Chamber and press `E` on the glowing altar. Enjoy the victory fanfare and `★ MISSION COMPLETE ★` banner!
