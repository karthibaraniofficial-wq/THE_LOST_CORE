- **Foliage & Props**: Low-poly pine trees, broadleaf bushes, barrels, crates, rune pillars.
- **The Ancient Vault**: Massive stone gate with sliding barrier, security terminal, and Core Altar.
- **The Lost Core**: Multi-faceted geometric power crystal with spinning orbital rings and emissive particle core.
